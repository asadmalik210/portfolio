# Asadullah Saeed Portfolio

Static portfolio website for Asadullah Saeed, a Senior iOS Developer.

## Send to a recruiter

Send the zipped `portfolio` folder. The recruiter can unzip it and open `index.html` directly in a browser. No website hosting is required.

## Preview locally without hosting

Double-click `index.html`, or open it from your browser with File > Open.

## Preview with a local server

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Deploy

This site can be hosted directly with GitHub Pages because it is plain HTML, CSS, JavaScript, and image assets.
